関数電卓 取扱説明書リファレンス

添付PDFマニュアルの全モード・52物理定数・302単位換算・特殊関数に完全対応

■ 5つの計算モード ([MODE]キー)

  • 0: NORMAL (一般) - 関数、微積分、Σ/Π、素因数分解、N進数
  • 1: STAT (統計) - 0:1変数(SD)〜7:各種回帰分析、[DATA]で表入力、[ALPHA]+[8(統計量)]で分析
  • 2: TABLE (数表) - 2つの関数 F1(X), F2(X) の開始値・ステップ数表作成
  • 3: COMPLEX (複素数) - 直交(a+bi)・極座標(r∠θ)計算、[MATH]で共役・偏角
  • 4: EQUATION (方程式) - 2元/3元連立1次方程式、2次/3次方程式ソルバー

■ セットアップ ([2ndF] → [SET UP])

  • 0: 角度単位 - DEG(度) / RAD(弧度) / GRAD(グラード)
  • 1: 表示桁数 - FIX(小数桁) / SCI(有効桁) / ENG / NORM1 / NORM2
  • 2: 編集形式 - W-VIEW (0:式通りの答 a/b,√,π / 1:小数) / LINE
  • 3: 濃度調整 - [+]/[-] で液晶コントラスト調整
  • 4: 入力方法 - INSERT / OVERWRITE
  • 5: 循環小数 - OFF / ON (例: 611÷495 = 1.2(34))
  • 6: 名前表示 - 電源OFF時に表示するユーザーネーム登録
  • 7: 言語設定 - 日本語 / ENGLISH

■ 特殊関数・機能ハイライト (説明書準拠)

・素因数分解: 計算後に [2ndF] [P.FACT(Exp)] (例: 12210= → 2×3×5×11×37)
・商と余り (int÷): 23 [2ndF] [int÷(STO)] 5 = → Q: 4, R: 3
・シミュレーション (ALGB): 文字式入力後に [2ndF] [ALGB(D1)] で変数に順次代入
・ソルバー (SOLVER): Xの式入力後に [2ndF] [SOLVER(D2)] で f(X)=0 の根を探索
・定積分 / 微分: [ALPHA] [∫dx] / [ALPHA] [d/dx]
・総和 Σ / 総乗 Π: [ALPHA] [Σ(×)] / [ALPHA] [Π(÷)]
・物理定数 (全52種): [ALPHA] [4(物理定数)] → 01(光速c)〜52(標準大気圧)
・単位換算 (全302種): 数値入力 → [ALPHA] [5(単位換算)] → 分類選択 → 001〜302
・機能メモリー (D1〜D3): [STO] [D1] の後に任意の関数キーを押してワンタッチ登録
・乱数 (RANDOM): [2ndF] [7(RANDOM)] (0:乱数, 1:ダイス, 2:コイン, 3:R.Int)
